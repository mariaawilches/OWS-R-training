What are R and RStudio?

O que são o R e o RStudio?

Two programs that work together. You will install both.

Dois programas que trabalham juntos. Vai instalar os dois.

R is a free programming language and program for statistics, data analysis and graphs. Instead of clicking menus, you write short instructions (called code), and R carries them out: it calculates, organises tables, makes graphs and runs statistical tests. R was created in the 1990s by Ross Ihaka and Robert Gentleman and is maintained today by the R Core Team; it is distributed through CRAN, the official R website.

RStudio is a free program, made by the company Posit, that gives R a comfortable window to work in. It shows, side by side, a place to write code, the results, the objects you have created, your files, graphs and help pages.

O R é uma linguagem de programação e um programa gratuitos para estatística, análise de dados e gráficos. Em vez de clicar em menus, escreve instruções curtas (o chamado código) e o R executa-as: faz contas, organiza tabelas, produz gráficos e faz testes estatísticos. O R foi criado nos anos 1990 por Ross Ihaka e Robert Gentleman e hoje é mantido pela R Core Team; é distribuído através do CRAN, o sítio oficial do R.

O RStudio é um programa gratuito, feito pela empresa Posit, que dá ao R uma janela confortável para trabalhar. Mostra, lado a lado, um sítio para escrever código, os resultados, os objectos que criou, os seus ficheiros, gráficos e páginas de ajuda.

Why use R?

Porquê usar o R?

  • It is free and runs on Windows, macOS and Linux.
  • Your work can be repeated. The code is a written record of every step, so you (or a colleague) can run it again next month on new data and get the same result. In Excel, clicks leave no record.
  • Packages written by researchers add about 20,000 extra tools, for surveys, maps, health data and more.
  • It reads almost anything: Excel, CSV, KoBo exports, SPSS and Stata files.
  • A large, friendly community writes free books, courses and forum answers, many in Portuguese.
  • É gratuito e funciona em Windows, macOS e Linux.
  • O trabalho pode ser repetido. O código é um registo escrito de cada passo, por isso pode (você ou um colega) voltar a executá-lo no próximo mês com dados novos e obter o mesmo resultado. No Excel, os cliques não deixam registo.
  • Os pacotes, escritos por investigadores, acrescentam cerca de 20 000 ferramentas extra, para inquéritos, mapas, dados de saúde e muito mais.
  • Lê quase tudo: Excel, CSV, exportações do KoBo, ficheiros SPSS e Stata.
  • Uma comunidade grande e simpática escreve livros, cursos e respostas em fóruns gratuitos, muitos em português.

Why use RStudio and not R alone?

Porquê usar o RStudio e não só o R?

R on its own opens a plain window where you type one command at a time. RStudio adds an editor to write and save scripts, shows your objects and graphs, helps you complete code as you type, and keeps everything for a piece of work together in a project. RStudio needs R to work; R works without RStudio, but it is much harder for beginners.

O R sozinho abre uma janela simples onde se escreve um comando de cada vez. O RStudio acrescenta um editor para escrever e guardar scripts, mostra os objectos e os gráficos, ajuda a completar o código enquanto escreve e mantém tudo o que pertence a um trabalho junto num projecto. O RStudio precisa do R para funcionar; o R funciona sem o RStudio, mas é muito mais difícil para quem começa.

Which program does the calculations?

Que programa faz os cálculos?

R is the engine. RStudio is the window you use to talk to R.O R é o motor. O RStudio é a janela que usa para falar com o R.

Can you use RStudio if R is not installed?

Pode usar o RStudio se o R não estiver instalado?

No. RStudio needs R. That is why you install R first, then RStudio.Não. O RStudio precisa do R. Por isso instala-se primeiro o R e depois o RStudio.

Create and save a script in RStudio

Criar e guardar um script no RStudio

  4. Save with Ctrl+S. Use a short name with no spaces or accents, ending in .R, for example first_script.R. RStudio marks a tab with unsaved changes; save often.
  1. File > New File > R Script (atalho Ctrl+Shift+N). Abre-se um separador vazio chamado Untitled1 no painel Source.

How R works: objects and functions

Como o R funciona: objectos e funções

Everything in R is either something (an object) or something that does something (a function).

Tudo no R é uma coisa (um objecto) ou uma coisa que faz algo (uma função).

Objects: giving a name to a value

Objectos: dar um nome a um valor

The arrow <- stores a value under a name. Read it as "gets". After you run it, the name appears in the Environment pane, and you can use it instead of the value. In RStudio, Alt+- types the arrow for you.

A seta <- guarda um valor com um nome. Leia-a como "recebe". Depois de a executar, o nome aparece no painel Environment e pode usá-lo em vez do valor. No RStudio, Alt+- escreve a seta por si.

Kinds of values

Tipos de valores

  • Numbers: 240, 2.5 (always a point for decimals).
  • Text (called "character"): always in straight quotes, "Macaneta".
  • Logical: TRUE or FALSE, the answer to a question such as ages > 14.
  • Missing value: NA ("not available").
  • Vector: several values of the same kind, made with c(). A table (data frame) is a set of vectors side by side, one per column.
  • Números: 240, 2.5 (sempre ponto nos decimais).
  • Texto (chamado "character"): sempre entre aspas direitas, "Macaneta".
  • Lógicos: TRUE ou FALSE, a resposta a uma pergunta como idades > 14.
  • Valor em falta: NA ("not available", não disponível).
  • Vector: vários valores do mesmo tipo, feito com c(). Uma tabela (data frame) é um conjunto de vectores lado a lado, um por coluna.

Functions: where do they come from?

Funções: de onde vêm?

Many functions come with R and are always ready: mean(), sum(), round(), c(). Thousands more come in packages, which you install and load (lesson 7). To learn what a function needs, read its help page: ?round.

Muitas funções vêm com o R e estão sempre prontas: mean(), sum(), round(), c(). Milhares de outras vêm em pacotes, que se instalam e carregam (lição 7). Para saber o que uma função precisa, leia a sua página de ajuda: ?round.

Seven rules for writing R

Sete regras para escrever R

  1. R treats capitals as different letters: Mean() is not mean().
  2. Text goes in straight quotes "...". Curly quotes copied from Word or PDF (“...”) cause errors.
  3. Decimals use a point: 2.5. The comma separates arguments: round(2.567, 1).
  4. Every ( needs a ), every " needs a closing ".
  5. Object names start with a letter, have no spaces or accents, and use _ to join words: travel_time.
  6. One instruction per line, with spaces around <- and after commas, so it is easy to read.
  7. Comment the why with #, for example # 99 means "not answered".
  1. O R distingue maiúsculas de minúsculas: Mean() não é mean().
  2. O texto vai entre aspas direitas "...". Aspas curvas copiadas do Word ou de um PDF (“...”) dão erro.
  3. Os decimais usam ponto: 2.5. A vírgula separa argumentos: round(2.567, 1).
  4. Cada ( precisa de um ), cada " precisa de outro " a fechar.
  5. Os nomes de objectos começam por uma letra, não têm espaços nem acentos, e usam _ para juntar palavras: tempo_viagem.

Spreadsheet habits that make analysis easy

Hábitos de folha de cálculo que facilitam a análise

Broman and Woo (2018), in a short and very readable paper, list rules for entering data in spreadsheets. The most useful for field teams:

Broman e Woo (2018), num artigo curto e muito legível, listam regras para introduzir dados em folhas de cálculo. As mais úteis para equipas de campo:

  • One table per sheet, starting in cell A1: first row = column names, one row per observation.
  • Short names without spaces or accents: travel_time_min, not "Travel time (min)".
  • One thing per cell: the number in one column, the unit in the name (not "14 years").
  • Leave missing values empty (or one agreed code written in the codebook). Never use 0 for "unknown".
  • Same spelling every time: "Walking", never also "walking" or "Walk ".
  • Dates as YYYY-MM-DD (2025-03-14). No colours or merged cells as information: R cannot read them.
  • Keep the raw file untouched, and write a codebook (a data dictionary) describing every column.
  • Uma tabela por folha, a começar na célula A1: primeira linha = nomes das colunas, uma linha por observação.
  • Nomes curtos sem espaços nem acentos: tempo_viagem_min, não "Tempo de viagem (min)".
  • Uma coisa por célula: o número numa coluna, a unidade no nome (não "14 anos").
  • Deixe os valores em falta vazios (ou um código combinado e escrito no livro de códigos). Nunca use 0 para "desconhecido".
  • Sempre a mesma escrita: "A pé", nunca também "a pé" ou "Pé ".
  • Datas como AAAA-MM-DD (2025-03-14). Sem cores nem células unidas como informação: o R não as lê.
  • Não mexa no ficheiro original e escreva um livro de códigos (dicionário de dados) que descreva cada coluna.

Factors: categories with an order

Factores: categorias com ordem

Tell R which categories exist and in which order.

Diga ao R que categorias existem e por que ordem.

R sorts text alphabetically. That is fine for site names, but not for answers like "Very unsafe … Very safe", and it is wrong for codes like 1 to 5 that stand for words. A factor stores a categorical variable together with its list of levels in the right order. Tables and graphs then follow that order.

O R ordena texto por ordem alfabética. Serve para nomes de locais, mas não para respostas como "Muito inseguro … Muito seguro", e está errado para códigos de 1 a 5 que representam palavras. Um factor guarda uma variável categórica junto com a lista dos seus níveis pela ordem certa. Tabelas e gráficos seguem então essa ordem.

survey <- survey |>
  mutate(feels_safe_f = factor(feels_safe, levels = 1:5,
                               labels = c("Very unsafe", "Unsafe", "Neutral", "Safe", "Very safe"),
                               ordered = TRUE))
inquerito <- inquerito |>
  mutate(sente_seguro_f = factor(sente_seguro, levels = 1:5,
                                 labels = c("Muito inseguro", "Inseguro", "Neutro", "Seguro", "Muito seguro"),
                                 ordered = TRUE))

Read it from the inside: factor() takes the numbers in feels_safe, says which values exist (levels = 1:5), what each one means (labels, in the same order) and that the order matters (ordered = TRUE). mutate() adds the result as a new column; you will learn it properly in Module 4.

Leia de dentro para fora: factor() pega nos números de sente_seguro, diz que valores existem (levels = 1:5), o que significa cada um (labels, pela mesma ordem) e que a ordem conta (ordered = TRUE). mutate() junta o resultado como nova coluna; vai aprendê-lo bem no Módulo 4.

Valores em falta (NA)

Find them, count them, and never hide them.

mutate() adds new columns calculated from the others (or replaces a column if you reuse its name). Two helpers create categories:

mutate() junta colunas novas calculadas a partir das outras (ou substitui uma coluna se repetir o nome). Duas funções ajudam a criar categorias:

The rules of cleaning

As regras da limpeza

Cleaning is part of the analysis, so it is done with code.

A limpeza faz parte da análise, por isso faz-se com código.

Real data are rarely ready to analyse. Cleaning often takes more time than the analysis itself. Done by hand in Excel, it leaves no record and cannot be repeated when new data arrive. Done with a script, every change is written down, can be checked by a colleague and can be run again in seconds.

Os dados reais raramente estão prontos a analisar. A limpeza leva muitas vezes mais tempo do que a própria análise. Feita à mão no Excel, não deixa registo e não pode ser repetida quando chegam dados novos. Feita com um script, cada alteração fica escrita, pode ser verificada por um colega e pode correr outra vez em segundos.

  • Never edit the raw file. Read it, clean it in R, save the result as a new file.
  • Look before you change. count() a column before recoding it; summary() before turning codes into NA.
  • Check after every step that the number of rows and the categories are what you expect.
  • Write down your decisions as comments: why 99 became NA, why a row was dropped.
  • Nunca edite o ficheiro original. Leia-o, limpe-o no R, guarde o resultado num ficheiro novo.
  • Olhe antes de mudar. Faça count() de uma coluna antes de a recodificar; summary() antes de transformar códigos em NA.
  • Verifique depois de cada passo que o número de linhas e as categorias são os que espera.
  • Escreva as suas decisões como comentários: porque é que 99 passou a NA, porque é que uma linha saiu.

Samples and populations

Amostras e populações

Why a result from a sample comes with uncertainty.

Porque é que um resultado de uma amostra vem com incerteza.

We rarely survey every student we care about (the population). We survey a sample and use it to learn about the population. A different sample would give a slightly different answer: this is sampling variability. Inference is the set of tools that tells us how far we can trust a result from one sample.

Raramente inquirimos todos os alunos que nos interessam (a população). Inquirimos uma amostra e usamo-la para aprender sobre a população. Outra amostra daria uma resposta um pouco diferente: é a variabilidade amostral. A inferência é o conjunto de ferramentas que nos diz até que ponto podemos confiar num resultado de uma amostra.

Compare two means

Is the difference between groups larger than chance would produce?

A hypothesis test starts from a null hypothesis, usually "no difference in the population". The p-value is the probability of seeing a difference at least as large as ours if the null hypothesis were true. A small p-value (by convention below 0.05) means the data are hard to explain by chance alone.

Um valor-p pequeno (por convenção abaixo de 0,05) quer dizer que os dados são difíceis de explicar só pelo acaso.

The OWS data are cross-sectional and observational: we measured everything at one moment and did not assign anyone to walk or to feel safe. A regression of well-being on feeling safe shows an association, but students who feel safe may also live in better-off households, which could raise well-being by itself (confounding); or students with better well-being may perceive their route as safer (reverse causation).

Os dados do OWS são transversais e observacionais: medimos tudo num momento e não pusemos ninguém a andar a pé ou a sentir-se seguro. Uma regressão do bem-estar em função de sentir-se seguro mostra uma associação, mas os alunos que se sentem seguros podem também viver em agregados com mais recursos, o que por si poderia aumentar o bem-estar (confundimento); ou os alunos com mais bem-estar podem ver o caminho como mais seguro (causalidade inversa).

  • Write "is associated with", not "causes" or "leads to", for observational data.
  • Report effect sizes with CIs, the n of each group and how many values were missing.
  • Small samples (for example one school, or the 4 students in "Other") give wide intervals: say so.
  • Many tests on the same data will produce some small p-values by chance. Decide your main questions before analysing.
  • Escreva "está associado a", não "causa" ou "leva a", para dados observacionais.
  • Indique tamanhos de efeito com IC, o n de cada grupo e quantos valores faltavam.
  • Amostras pequenas (por exemplo uma escola, ou os 4 alunos em "Outro") dão intervalos largos: diga-o.
  • Muitos testes nos mesmos dados vão dar alguns valores-p pequenos por acaso. Decida as perguntas principais antes de analisar.

Protecting the data of children

Proteger os dados das crianças

OWS data are about minors. Treat them with extra care.

Os dados do OWS são sobre menores. Trate-os com cuidado redobrado.

The real OWS data describe children: where they live, how they travel, how safe they feel, their well-being. Even without names, a combination of school, age, sex and route can identify a child in a small community. Protecting these data is part of doing the analysis well, and a condition of the ethics approval and the consent the families gave.

Os dados reais do OWS descrevem crianças: onde vivem, como se deslocam, quão seguras se sentem, o seu bem-estar. Mesmo sem nomes, uma combinação de escola, idade, sexo e caminho pode identificar uma criança numa comunidade pequena. Proteger estes dados faz parte de fazer bem a análise, e é uma condição da aprovação ética e do consentimento dado pelas famílias.

  • Use only what you need. Analyse a copy without names, phone numbers or exact GPS points, unless the question requires them.
  • Pseudonymise. Use codes such as CH001. Keep the key linking codes to names separately, with restricted access.
  • Store securely, only in the storage approved by the project (encrypted laptop or approved institutional drive). Never on a personal USB stick or in an email attachment.
  • Never upload real data to online tools that the project has not approved: Posit Cloud, online converters, AI chatbots. Use the fictitious data for practice and for asking for help.
  • Publish only aggregated results, and avoid tables with very small cells (for example fewer than 5 children) that could point to one child.
  • Follow the study protocol, the consent forms, the OWS data management plan and the rules of your institution and country. When in doubt, ask the data manager before acting.
  • Use só o que precisa. Analise uma cópia sem nomes, telefones ou pontos GPS exactos, a não ser que a pergunta os exija.
